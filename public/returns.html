Returns and refunds

Our return policy

Each seller sets their own return policy on their shop page. Buyers can request returns or refunds through their order details when the policy permits.

When refunds are handled

  • If a seller cannot fulfil an order.
  • If an order is cancelled before postage is applied.
  • If the marketplace resolves a dispute over a listing.

Restocking policy

Return shipping and restocking fees, if any, are set by individual sellers and shown at request time.

Cancelled vs refunded

A cancelled order restores the payment to you (according to the seller's policy) and stock is restored for available items. A refunded order has the payment reversed by the provider.
